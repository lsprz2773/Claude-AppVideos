# Plantilla de video

Plantilla para crear videos promocionales por fases con Claude Code.

1. Clona este repo en la carpeta del video.
2. Completa `brief.md` y copia `.env.example` a `.env`.
3. Abre Claude Code dentro de la carpeta y pide: "haz el video según brief.md".

Lee `CLAUDE.md` para ver el flujo completo y las reglas de ramas.
